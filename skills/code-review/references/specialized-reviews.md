# Code Review — Specialized Reviews

## Specialized Reviews

Apply the selected review lenses to the shared diff and assignment. Each lens returns its own findings, coverage or applicability, and evidence at a changed file and line. The context pre-flight supplies verified assignment and fixture data. Business conformance, security controls and coverage keep their established report sections. Preserve the delegated-security input and its verified delivery when supplied.

For database work, determine the engine once from the connection in `config/database.php`, the documented default in `.env.example`, and the dependency and schema evidence. Record the source of that decision; when it remains unknown, mark the engine unverified. A MySQL schema feature, a PostgreSQL deploy-safety concern, Redis access cost and a query plan each cover a different question.

## Highest-Priority Fast Track

Return each actionable Critical or Moderate finding with its affected line, supporting evidence, violated rule, and the minimal correction. Reuse a verified upstream finding on the same defect.
